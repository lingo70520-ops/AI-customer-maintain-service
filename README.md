AI 智慧客戶維繫服務 一、專案目的 建立一個可以跨產業使用的 AI 智慧客戶維繫服務。 主要解決企業在客戶購買產品或服務後， 沒有持續追蹤、互動與維繫客戶的問題。 系統希望協助企業：
整理客戶資料
了解客戶目前購買的產品或服務
了解客戶最後互動時間
判斷客戶目前狀態
提供 AI 維繫建議
建議適合的聯絡方式
產生適合的聯絡內容## 專案簡介

AI 智慧客戶維繫服務是一套以客戶資料分析、互動時機判斷與後續行動建議為核心的智慧化客戶管理工具。系統採用 HTML5、CSS3、JavaScript 建置前端介面，並運用 RWD 響應式網頁設計，讓使用者可於電腦、平板及手機瀏覽。

透過 SheetJS 技術支援 Excel（XLSX／XLS）及 CSV 客戶資料匯入，並在瀏覽器本地端完成欄位辨識、日期格式轉換、產品標準化與資料處理，降低客戶個資外傳風險。

系統以 JavaScript 規則引擎模擬 AI 智慧分析，依據客戶的購買產品、產品階段、購買日期及時間間隔，自動判斷客戶目前狀態，並提出下一步產品或服務建議。Dashboard 可呈現客戶統計、待處理名單及智慧維繫建議，並支援 Email、LINE、SMS 等多元溝通情境。目前亦可依分析結果自動產生個人化 Email 草稿，協助企業在適合的時間，以適合的方式持續與客戶建立連結。

## 使用技術

- RWD 響應式網頁設計
- SheetJS
- Excel / CSV 資料處理
- Dashboard
- JavaScript 規則引擎
- 資料標準化
- 本地端資料處理

- 個人化 Email 草稿生成

## 系統核心流程

客戶資料 → 資料標準化 → 智慧分析 → 維繫時機判斷 → 溝通方式 → 個人化訊息 → 下一步行動
